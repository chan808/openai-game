# ECHO

시간 조작과 위치 이동을 중심으로 실험하는 브라우저 탑다운 액션 게임이다.

현재는 사방 벽과 두 기둥이 있는 단일 화면에서 이동, 조준, 기본 공격과 검병·궁병 조합의 조작감을 확인하는 전투 프로토타입 단계다. 화면보다 큰 맵, 방패병, 마법사, 장비 드롭과 적응형 진행 구조는 현재 지형 전투를 직접 플레이한 뒤 한 단계씩 검증한다.

## 기술

- Vite

## 현재 조작

- `WASD`: 이동
- 포인터와 왼쪽 클릭: 조준과 기본 공격
- `1`, `2`, `3`: 롱소드, 활, 마법 전환
- 기본 `R`: 충전이 가득 찼을 때 시간정지 궁극기 발동, 기록 중 다시 눌러 조기 재생
- 기본 마우스 오른쪽 클릭: 커서 방향으로 순간이동
- `Tab`: 전투를 정지하고 스킬창 열기·닫기

하단의 Q, E, R, Space와 마우스 오른쪽 버튼 슬롯에는 스킬창에서 순간이동과 시간정지를 드래그해 배치할 수 있다. 순간이동 출발점의 잔상에 적의 확정된 공격을 맞히면 궁극기가 충전된다. 시간정지를 발동하면 최대 10초 동안 플레이어만 자유롭게 행동한다. 제한 시간이 끝나거나 궁극기를 다시 누르면 기록한 이동과 모든 무기 공격을 5배속 잔상으로 재생하며, 이때 적의 피해와 사망이 순서대로 반영된다.

Cloudflare 로그인이 완료된 환경에서는 `npm run deploy:preview`로 공유 가능한 Preview를 만들고, `npm run deploy`로 프로덕션에 배포할 수 있다. 평소에는 GitHub와 연결된 Cloudflare Workers Builds를 사용한다.

구체적인 키 배정과 튜닝 값은 아직 확정 사양이 아니다.
