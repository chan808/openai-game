# Development Log

완료된 개발 작업과 실제 판단만 남기는 기록이다. 대회 제출 문안이나 일정표로 사용하지 않는다.

## 기록 원칙

- 날짜를 채우기 위해 매일 쓰지 않고, 의미 있는 작업 단위가 끝났을 때만 추가한다.
- 계획이나 예상 성과 대신 실제 변경, 사용자 판단, 검증 결과를 기록한다.
- 한 항목은 아래 형식을 유지하되, 남길 내용이 없는 줄은 생략한다.
- 커밋을 만든 뒤 식별 가능한 짧은 해시를 적는다.

## 작성 형식

### YYYY-MM-DD — 작업 단위

- Commit: `<short hash>`
- Codex 작업: 변경하거나 제안한 핵심
- 사용자 판단: 플레이테스트나 검토 뒤 사용자가 확정한 내용
- 검증: 실행한 테스트와 결과
- 남은 쟁점: 다음 작업에 실제로 영향을 주는 항목만 기록

첫 기록은 세팅 또는 구현 작업을 커밋한 뒤 추가한다.
